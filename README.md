# Wallet Exchange

Решение задачи по проектированию внутреннего модуля обмена валют в пользовательском кошельке.

**[Открыть интерактивный прототип](https://pajamaserj.github.io/wallet-exchange-design/)**

Прототип работает прямо в браузере, без установки и авторизации.

## Что важно знать

Курс USDT/RUB в прототипе не задан вручную — он загружается через реальный внешний API CoinGecko и повторно проверяется перед созданием заявки.

При этом балансы, заявки, резервирование средств и история операций работают как демонстрационная модель в браузере. Реальные деньги и финансовый backend не используются.

## Что можно посмотреть в прототипе

Прототип позволяет:

- менять направление обмена RUB → USDT и USDT → RUB;
- вводить сумму и сразу видеть результат конвертации;
- учитывать доступный баланс;
- подтверждать обмен;
- просматривать историю заявок.

Также предусмотрены основные ошибочные ситуации: недостаточный баланс, изменение курса, недоступность курса и техническая ошибка.

В меню с шестерёнкой находится тестовый режим. Через него можно вручную включить изменение курса, ошибки и разные результаты обработки заявки.

## Почему в проекте получилось больше требований, чем было нужно минимально

На этапе анализа я намеренно описал дополнительные состояния и правила: повторную проверку курса, резервирование средств, промежуточный статус заявки и защиту от повторного создания операции.

Они нужны не для усложнения решения, а чтобы интерактивный прототип был наглядным и показывал поведение обмена не только в идеальном сценарии.

Полноценный финансовый backend в рамках задачи не разрабатывался.
