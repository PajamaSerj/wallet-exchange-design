## Локальный запуск

Из корня репозитория:

```bash
python -m http.server 8000
```

Открыть:

```text
http://localhost:8000/prototype/
```

Запуск через локальный HTTP-сервер предпочтительнее прямого открытия `file://`, поскольку браузерная политика может ограничивать сетевые запросы к CoinGecko.

## Поддержанные состояния

Прототип поддерживает:

- initial, quote loading, quote ready и quote error;
- RUB → USDT и USDT → RUB;
- ввод исходной суммы, авторасчёт, «Обменять всё»;
- пустой, некорректный, нулевой, отрицательный, дробный ввод;
- минимум и недостаточный доступный баланс;
- обычное подтверждение и изменившийся результат;
- processing с заблокированной кнопкой;
- sync `completed`;
- `pending` с активным резервом;
- async `completed` и `rejected`;
- техническую ошибку;
- локальную историю;
- идемпотентный повтор демонстрационного ключа;
- desktop и mobile.

Полный индекс — в [`ux-spec.md#ux-08`](ux-spec.md#ux-08).

## Известные ограничения

- Реальным внешним источником является только CoinGecko Simple Price API.
- Балансы, заявка, резерв, статусы, дополнительная проверка и история — клиентская demo-симуляция.
- `localStorage` относится только к текущему браузеру и устройству.
- Demo-изменение курса и выбор terminal-результата не являются production-правилами.
- Production-backend, аудит финансовых операций, авторизация, KYC/AML, уведомления, отмена, комиссия и спред отсутствуют.
- Окончательные формат больших чисел и часовой пояс остаются открытыми по `OQ-M-01` и `OQ-M-02`.
