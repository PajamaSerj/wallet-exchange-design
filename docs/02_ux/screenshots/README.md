# Prototype Screenshots — Historical Archive

**Статус:** ARCHIVE / NOT CURRENT  
**Дата создания:** 2026-08-05

Файлы в этом каталоге были созданы для первой реализации CHAT-03. После ручного UX-review интерфейс был существенно переработан и принят пользователем в другой компоновке.

Сами `.webp` сохранены без изменений для истории работы и Prompt Log, но:

- они не показывают финальный принятый UX/UI;
- они не используются как актуальное доказательство результата CHAT-03;
- на них не следует ссылаться как на текущий вид desktop или mobile;
- основной формат передачи — публичный интерактивный прототип:
  [https://pajamaserj.github.io/wallet-exchange-design/](https://pajamaserj.github.io/wallet-exchange-design/).

Актуальная структура и состояния описаны в [`../ux-spec.md`](../ux-spec.md), а сведения о публикации — в [`../prototype-link.md`](../prototype-link.md).
