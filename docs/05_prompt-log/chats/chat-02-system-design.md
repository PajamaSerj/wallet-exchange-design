## Ошибки, галлюцинации и ручные исправления

| Наблюдение | Риск | Как обнаружено | Исправление |
|---|---|---|---|
| Первичная расширенная версия SDD была избыточно подробной для высокоуровневого scope | превращение SDD в детальный технический проект | сверка с запретами этапа 2 | сокращены технологические детали, оставлены логические компоненты и бизнес-границы |
| Возможный вариант специальной суммы для `pending` выглядел как реальное финансовое правило | ложное production-требование | сравнение вариантов по `AS-003` | выбран явный demo-переключатель, специальная сумма отклонена |
| Можно было неявно превратить логические компоненты в микросервисы | необоснованная архитектура | проверка ограничения scope | зарегистрирован `DEC-037`, стек и deployable-границы не выбирались |
| Ошибка резервирования могла оставить заявку в `created` | нарушение терминальной границы | проверка lifecycle и инвариантов | после устойчивого создания такая заявка переводится в `rejected`; до создания ошибки не создают заявку |
| Повтор async-события мог повторно изменить баланс | двойное финансовое применение | проверка инвариантов 1, 2, 5, 9 | добавлены атомарные границы и терминальная идемпотентная защита `DEC-038`/`DEC-040` |
| Чисто визуальные требования могли быть ошибочно отмечены покрытыми SDD | ложная трассировка | построчная проверка матрицы | `UX-*`, `CON-010` и непокрытый `UR-014` оставлены без SDD-доказательства |

## Ручные проверки

- поиск запрещённых статусов `cancelled`/`expired` выполнялся только для подтверждения их отсутствия как состояний; слова встречаются лишь в явных запретах;
- проверено, что активный резерв относится только к `pending`;
- проверено освобождение резерва при `rejected`;
- проверено различие подтверждённых и фактических async-значений;
- проверено, что диаграммы используют тот же lifecycle, что и SDD;
- проверено, что в матрице не установлено `VERIFIED`;
- UX, Gherkin, OpenAPI и прототип не создавались и не отмечались выполненными.
