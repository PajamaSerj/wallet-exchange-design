## Отклонённые варианты

| Тема | Отклонённый вариант | Причина |
|---|---|---|
| Граница модуля | Заканчивать ответственность сразу после регистрации заявки | Не обеспечивает согласованный пользовательский результат обмена |
| Ввод суммы | Разрешить редактировать исходную и целевую сумму | Усложняет валидацию первой версии; выбран ввод только исходной суммы |
| Минимум | 1 единица любой исходной валюты | Не обеспечивает одинаковый экономический минимум в двух направлениях |
| Изменение курса | Сравнивать полное значение API | Может вызывать подтверждение из-за невидимых пользователю знаков |
| История | Память вкладки | Теряет записи после перезагрузки |
| История | Полноценный backend/БД | Необоснованно расширяет демонстрационный scope |
| Уведомления | Создать отдельную систему уведомлений для `pending` | Явно исключена пользователем |
| Визуальный ориентир | Требовать новые скриншоты Bidzaar | Пользователь разрешил использовать доступные публичные изображения и аналитическую интерпретацию |
| Отмена | Добавить `cancelled` и пользовательскую отмену | Недостаточно требований; функция исключена |
| Курс | Показывать таймер истечения | Пользователь отказался от отображения срока действия |
