## Правила актуализации

- Рабочий чат заменяет `PLANNED` на ссылку только при фактическом покрытии поведения.
- Диапазон ID означает одинаковое доказательство для каждого требования внутри диапазона, а не объединение требований.
- Ссылка в UX/UI указывает на конкретный раздел спецификации; код и screenshots являются связанными доказательствами из этого раздела.
- `VERIFIED` не устанавливается рабочими чатами.
- Gherkin и OpenAPI остаются `PLANNED`, пока профильные артефакты не подготовлены.
- Изменение требования одновременно отражается в реестре, матрице и журнале решений.
