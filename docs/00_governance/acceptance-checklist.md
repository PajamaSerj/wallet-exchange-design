## Поведение обмена — критерии для будущих этапов

- [ ] **EXC-01:** Поддерживаются только RUB → USDT и USDT → RUB.
- [ ] **EXC-02:** Пользователь вводит только исходную сумму; получаемая сумма рассчитывается.
- [ ] **EXC-03:** Минимум равен эквиваленту 1.0 USDT в обоих направлениях.
- [ ] **EXC-04:** Максимум равен доступному балансу исходной валюты.
- [ ] **EXC-05:** Ввод целочисленный, результат округляется до одного знака после точки.
- [ ] **EXC-06:** Курс получается из согласованного CoinGecko endpoint.
- [ ] **EXC-07:** Котировка имеет отдельный идентификатор и время источника.
- [ ] **EXC-08:** Курс загружается при открытии формы и повторно проверяется при отправке.
- [ ] **EXC-09:** Повторное согласие требуется только при изменении отображаемой получаемой суммы.
- [ ] **EXC-10:** Обычное и изменённое подтверждение соответствуют согласованным потокам.
- [ ] **EXC-11:** Одновременно видны балансы RUB и USDT.
- [ ] **EXC-12:** Доступный баланс проверяется при вводе и перед созданием заявки.
- [ ] **EXC-13:** «Обменять всё» использует доступный, а не общий баланс.
- [ ] **EXC-14:** Одна пользовательская попытка создаёт не более одной заявки и одного изменения баланса.
- [ ] **EXC-15:** Используются только `created`, `pending`, `completed`, `rejected`.
- [ ] **EXC-16:** `pending` резервирует исходную сумму.
- [ ] **EXC-17:** `completed` применяет обмен, `rejected` освобождает резерв.
- [ ] **EXC-18:** История заявок сохраняется в `localStorage` текущего браузера.
- [ ] **EXC-19:** Перед асинхронной обработкой показано предупреждение о возможном изменении курса и суммы.
- [ ] **EXC-20:** Пользовательская отмена и отдельные уведомления отсутствуют.
- [ ] **EXC-21:** Комиссия, спред и дополнительные лимиты отсутствуют.
- [ ] **EXC-22:** Покрыт согласованный каталог ошибок и исключительных состояний.
- [ ] **EXC-23:** Сообщения понятны пользователю и не раскрывают внутренние детали.
- [ ] **EXC-24:** Асинхронный сценарий воспроизводим в демонстрации.
- [ ] **EXC-25:** Для асинхронного `completed` различаются подтверждённые и фактические значения.
